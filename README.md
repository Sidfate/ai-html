# AI专业研究生择校指南

面向 AI 开发方向的交互式研究生择校参考页面，使用单个静态 HTML 文件，无需安装依赖或构建。

## 功能

- 国内 Top 20 与境外 Top 10 分页签展示，可展开完整候选池。
- 五维专业度模型，支持调整权重、实时重排和查看官方材料依据。
- 支持关键词、城市、学位、方向及分数/学费筛选。
- 支持收藏、最多四个项目对比、导出 CSV。

## 数据口径

数据快照为 2026 年 9 月 30 日。排名是候选池内的人工等级加权初评，非官方榜单。
国内院复试线与拟录取统计分别标注；未核验项目保留说明。实际报考以当年学校公告为准。
收藏和筛选偏好仅存访问者自己的浏览器，不传输到服务器。

## GitHub Pages

发布源选择 `main` 分支的根目录 `/`，首页为 `index.html`；`.nojekyll` 用于直接发布静态文件。
之后修改 `index.html` 并推送到 `main`，GitHub Pages 会更新页面。
